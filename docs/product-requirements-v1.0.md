# JH-Agent OS 产品需求规格 v1.0（需求阶段）

来源：用户于 2026-10-11 提供，经过 32 轮提问整理。
本文整理标题与排版，保留需求原意。实现路线见 [ROADMAP.md](../ROADMAP.md)，当前完成状态见 [STATUS.md](../STATUS.md)；需求文本不代表实现或验收通过。

## 一、项目定义

项目名称：JH-Agent OS。

产品定位：基于 Codex 的个人 AI Agent 增强系统。

JH-Agent OS 不替代 Codex，而是利用 Codex 作为核心工作环境，将其扩展为能够协调多模型、管理复杂目标、持续推进项目的个人智能工作系统。

## 二、核心目标

用户提出较高层级目标，由 Agent 完成：

- 理解目标；
- 制定计划；
- 调用合适模型；
- 执行任务；
- 验证结果；
- 修正错误；
- 持续推进。

从 AI 编程助手升级为个人 AI 工作系统。

## 三、固定约束

### 1. Codex 为核心环境

- 基于 Codex 开发；
- 在 Codex 内使用；
- Codex 是主要交互入口；
- 不建设独立 AI 平台。

### 2. 优先复用 Codex 能力

以下基础能力不重复建设：

- 基础 Coding；
- 文件操作；
- Git 工作流；
- 基础 Agent 执行；
- 项目上下文；
- 基础记忆；
- 基础工具调用。

JH-Agent OS 关注 Codex 上层能力增强。

## 四、核心使用场景

### 1. 软件开发

用户提出软件目标，Agent 分析需求、制定方案、调用 Worker、完成实现、测试和审核。

### 2. 研究与决策

解决复杂技术或战略问题：收集信息、比较方案、验证并输出决策建议。

### 3. 长期项目管理

管理持续数周或数月的项目，包括阶段规划、状态追踪、风险识别和下一步规划。
Agent 需要理解整个项目的发展状态。

### 4. 工作机制优化

通过历史任务经验改进任务拆解、模型选择和 Workflow 成功率。

## 五、核心能力需求

### 1. 多模型协作

让 Codex 协调多个专业模型。

| 角色 | 当前模型 / 环境 |
|---|---|
| 主控 | Codex |
| 执行 Worker | Gemini Flash |
| 审核 Reviewer | Muse 1.3 |
| 高级决策 | GPT-6.1 sol |

支持模型角色分工、动态调用、结果汇总和审核反馈。

### 2. 智能资源调度

根据任务选择模型、调用次数和验证深度，考虑复杂度、风险、成本与质量要求。

### 3. 长期项目管理

管理项目目标、阶段、任务、状态、风险和历史决策。

### 4. 动态权限管理

根据任务类型、风险和项目重要性，决定自动执行、审核或请求授权。

### 5. 失败恢复机制

失败 → 自主诊断 → 修改方案 → 重新尝试 → 超过限制 → 升级高级分析。

重点区分 Bug、方法错误和方向错误。

### 6. 分级质量验收

避免把模型认为正确等同于正确，区分已验证事实、推测、风险和未解决问题。

### 7. Workflow 管理

当前采用混合 Workflow：简单任务使用固定流程，复杂任务动态规划。
未来依据成功率、任务数据和评价结果进行 Workflow 自优化。

### 8. 经验沉淀

当前方向（C）：自动提取经过验证的经验。
未来方向（D）：经验影响 Workflow、模型选择和执行策略。

## 六、模型策略

当前采用自适应资源调度，按任务选择资源，不要求所有任务使用最强模型。

优先使用已有资源，避免无意义调用。

## 七、自主程度

采用动态自主：

- 简单任务自动完成；
- 复杂任务自主规划执行；
- 高风险任务请求确认。

## 八、自我优化

当前采用分级自主优化，允许 Prompt、Workflow 和模型选择优化。
不能自动扩大权限。

未来发展为系统级自我迭代。

## 九、第一阶段 MVP

核心目标：完成多模型协作闭环。

用户目标 → Codex 主控 → 任务规划 → Gemini 执行 → Muse 审核 → Codex 修正 → 交付。

第一阶段暂缓：

- 完整自主 Agent Runtime；
- 独立 UI；
- 完整经验学习系统；
- 全天候云端运行；
- 系统级自我修改。

## 十、未来演进路线

| 产品阶段 | 目标与新增能力 |
|---|---|
| Phase 1 | 多模型协作闭环，证明系统能可靠工作 |
| Phase 2 | 项目管理能力：长期状态、任务规划、项目推进 |
| Phase 3 | 评价与学习：JH-Eval、JH-Audit、经验优化 |
| Phase 4 | 高级自主系统：长期自主运行、更强自我优化、更复杂任务管理 |

## 十一、当前阶段结论

构建一个让 Codex 能够协调多个智能体、管理长期目标、持续优化工作方式的个人 AI 操作层。
